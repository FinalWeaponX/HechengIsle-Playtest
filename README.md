## r45 更新

- 修复标题菜单「继续游戏」的存档排序。写入中断时，可从上一份完整存档恢复，损坏的存档记录不会卡住存档列表。
- 背包已满时，柜台购买和邮箱取件会提示清理物品。腾出空间后可回到原柜台或取件点继续，取件成功时才扣款。
- 改善店铺进出、读档和场景切换时的店员与界面清理，修复重返雾灯岛后渡轮时刻表和滚动新闻的显示问题。
