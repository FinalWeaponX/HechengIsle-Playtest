## r42 更新

- 修复雾灯岛 13 家街边店和玩家分店进门后陈设消失、镜头被门头遮挡的问题，也修复了集市营业时店员缺席的情况。
- 新增飞行俯仰、连续滚转和手动调平，战机可升至 1200 米，普通飞行器可升至 600 米。空战导航跟踪当前敌机或训练靶。
- 补充高空云层，修复穿云、远景和切换菜单时的云层消失。击毁敌机时会轮换四种体积爆炸效果。
- 补齐高空台地和码头护栏碰撞，修正停机坪标线、天梯地面、车辆尾灯和大型飞行器遮挡。
- 钓鱼和出海时可查看时间。近岸船钓增加抛竿和提鱼演出，外海求救事件加入救援小游戏。按住 **Y** 可打开载具召唤轮盘。
