## r33「出航与导航」

在发布页的 **Assets** 下载 `Hecheng-Windows-x64-2026-11-05-r33.zip`。完整解压，进入 `Hecheng-Windows-x64` 文件夹，双击 **Hecheng.exe**。适用于 Windows 64 位，显卡需支持 Vulkan。可继续使用原试玩存档。

- 码头上下船、浅水脱浅和左侧沙坡已修复。按 **I** 可召回已购载具及初始自行车、木船。
- 完成码头小赛后，看小地图下方的主线卡，依次完成三鱼考核、海叔路亚课和首航。三种考核鱼四季全天可钓，历史亲钓纪录可登记，进度跨天保留。
- 点右上小地图或按 **M** 查看建筑入口、钓位、当前位置和任务。
- 卖鱼、海上买卖和换鱼都能调数量，提供加减与最大。海星可拾取或以极低概率在自由钓鱼时附带获得，阿舟收购价20，鱼市26。
- 室内转角镜头、窗外草地和反馈中的建筑穿模已修复。送货目的地与理货图形每局变化。

**WASD** 移动或游泳 · **空格** 跳跃 · **E** 交互 · **F** 上下载具 · **V** 切换视角 · **Tab** 背包 · **F5 / F9** 存档 / 读档。完整说明见试玩包内的 `README.txt`。
